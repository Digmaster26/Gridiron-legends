# Gridiron Legends Mobile

Native Android app shell with an offline bundled WebGL 3D football prototype.

## Build
Open this folder in Android Studio (Ladybug or newer), allow Gradle to sync, then:
Build > Build Bundle(s) / APK(s) > Build APK(s)

The app is landscape-only and uses Android WebView to run the bundled WebGL game locally.

This project intentionally uses original procedural graphics and no official league logos or player likenesses.
